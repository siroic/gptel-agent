** TODO Add policy-based Agent Router to gptel-agent fork
:PROPERTIES:
:AREA: gptel-agent

*** Goal
Add a routing hook that selects sub-agent execution policy from project/task/role metadata while reusing existing `gptel-agent` preset-based delegation.

*** Current finding
`gptel-agent` already supports per-sub-agent `gptel` preset keys, including model/backend. The missing feature is policy-based routing before delegated execution.

*** Implementation target
Patch delegation around `gptel-agent--task`.

*** Proposed API
#+begin_src elisp
(defcustom gptel-agent-route-function nil
  "Function called before sub-agent execution to return extra preset keys.")
#+end_src

*** Route function input
#+begin_src elisp
(:subagent-type TYPE
 :description DESCRIPTION
 :prompt PROMPT
 :agent AGENT
 :buffer CURRENT-BUFFER
 :org-properties PROPS)
#+end_src

*** Route function output
#+begin_src elisp
(:backend BACKEND
 :model MODEL
 :tools TOOLS
 :max-tokens MAX-TOKENS)
#+end_src
